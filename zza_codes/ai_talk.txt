CREATE TABLE module_slots (
    msid     INTEGER PRIMARY KEY AUTOINCREMENT,
    eid      TEXT    REFERENCES equipments (eid) ON DELETE CASCADE
                     NOT NULL,
    slot_id  TEXT    NOT NULL,
    required INTEGER NOT NULL,
    inherit  INTEGER
);
倒数第二步也是最复杂的一步：
以下面的例子：
module_slots的：
eid标明所属装备：medium_tank_chassis
msid标明自身id：内部自动分配
slot_id：main_armament_slot/turret_type_slot/armor_type_slot
required：yes/no
inherit：NULL/1/0，inherit为1时，直接填 "slot_id = inherit"
CREATE TABLE allowed_module_categories (
    msid             INTEGER NOT NULL
                             REFERENCES module_slots (msid) ON DELETE CASCADE,
    module_categorie TEXT    NOT NULL
);
allowed_module_categories.msid对应module_slots.msid
module_categorie即为：allowed_module_categories中的tank_small_main_armament等属性
处理前前查询equipments.module_inherit是否为1，如果是，则打印警告，然后接着输出（不要continue）
